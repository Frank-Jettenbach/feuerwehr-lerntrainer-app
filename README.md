# Lerntrainer FF Jettenbach – Truppmann Teil 1 (RLP)

Lern-App für die Truppmannausbildung Teil 1 der **Freiwilligen Feuerwehr Jettenbach**.
Hier liegen nur die fertigen Android-Apps; der Quellcode ist nicht öffentlich.

## Installieren
1. Unter [Releases](../../releases/latest) die Datei `FeuerwehrLerntrainer.apk` herunterladen
   (die App heißt auf dem Handy „Lerntrainer FF Jettenbach“).
2. Öffnen und „Installation aus unbekannten Quellen“ für den Browser bzw. Dateimanager erlauben.

Neue Versionen lassen sich einfach darüber installieren, der Lernstand bleibt erhalten.
Die App zeigt auf der Startseite an, wenn ein Update bereitsteht.

## Schon die alte App „Feuerwehr Lerntrainer“ installiert?
Die neue App wird daneben installiert. Beim Start erkennt sie die alte Version und führt durch
die Übernahme des Lernstands und das Entfernen der alten App.
